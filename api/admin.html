历史记录：导出 → 修改 → 上传

  1. 导出：在「记录」页设置好日期、分类筛选后，点「导出Excel」，得到当前筛选结果的 Excel（含 ID、日期、时间、描述、金额、分类）
  2. 修改：在 Excel 的「明细」表中修改需要改的列（不要改或删 ID 列）：
    • 日期（格式：2026-01-15）
    • 时间（格式：14:30）
    • 描述、金额、分类（可改为新分类名，系统会自动识别）
  3. 上传：修改完成后，在上方选择文件或拖拽到上传区域，系统按 ID 批量更新对应记录
⚠️ 注意事项
  • 不要删除或修改 ID 列，否则无法匹配记录
  • 不能新增或删除记录行，只能修改现有记录
  • 日期格式必须为：YYYY-MM-DD（如：2026-01-15）
  • 时间格式必须为：HH:MM（如：14:30）
  • 金额必须是数字，支持小数（如：35.50）
  • 分类可以输入新名称，系统会自动创建新分类

用表格改分类（下载 → 编辑 → 上传）

  1. 下载：点下面「下载分类映射表」，得到当前所有类目的表格（含原分类、新分类）。
  2. 编辑：在表格里改「新分类」列，把要归成一类的改成同一个名字。例如 早餐、晚餐 的新分类都改成 正餐，打车、加油 都改成 出行。也可用一列写「新分类----原分类」，如：正餐----早餐、正餐----晚餐、出行----打车、出行----加油。
  3. 上传：保存表格后点「上传映射表」，选你改好的文件。系统会按表合并，记录和映射都会更新。
  4. 若你在表里删掉了某一行（例如删掉 早餐、晚餐），上传后会提示：这些类目的记录需要重新归到哪个分类。下面会出现「待处理」，为每组选一个要归入的分类点确定即可。
待处理：以下类目已从表中删除，请为每组选择要归入的分类
手动合并

选择要合并的分类 → 合并为（填目标名）→ 合并。记录和映射都会更新。

新增类目

直接填写类目，可多级用 | 分隔，如 正餐、正餐|早餐、正餐|晚餐|外卖。

🖥️ 网页端功能

  • 数据概览：查看今日/本周/本月支出统计
  • 记录列表：查询、筛选、编辑、删除记录
  • 表格统计：按年/月/日查看支出明细
  • 图形统计：分类占比图、趋势图
  • 批量导入：上传Excel批量修改记录
  • 分类管理：查看和重命名分类
  • 外债：管理「我欠别人」的欠款，新增、还款、删除
  • 设置：自定义帮助回复内容
